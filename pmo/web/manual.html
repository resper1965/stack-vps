Manual operacional — ambiente stack

Um ambiente de desenvolvimento remoto único: você e os agentes trabalham na VPS, o laptop é só terminal. Acessível de qualquer lugar sem porta aberta, um projeto não atrapalha o outro, e tudo é recriável pelos scripts do repositório stack-vps.

1 Visão geral

Princípios

  • Fechada. Nenhuma porta responde na internet. Entrada só pela tailnet; o túnel Cloudflare é o segundo caminho.
  • Isolada. Ferramenta pesada ou arriscada roda em container; o sistema base fica enxuto.
  • Recriável. Formatar a VPS e rodar os scripts na ordem devolve o ambiente; o restante vem do restore do R2.
  • Menor privilégio. Agentes rodam como agente, sem sudo, com Docker rootless. dev é o admin.

3 Agentes & modelos

O dia a dia de desenvolvimento é com Claude Code e Codex. Os modelos do comando modelo e o Continue no VS Code são para teste de segurança, não para o dev comum.

Agentes

Claude Code dev

Duas contas: bekaa (~/.claude, padrão) e ionic (~/.claude-ionic).

Força a conta: claude-bekaa / claude-ionic. A extensão do VS Code usa sempre a bekaa.

Codex dev

No ChatGPT Pro por padrão. codex -p openrouter usa o OpenRouter.

Featherless não entra no Codex (só fala a Responses API).

Antigravity (agy) dev

CLI de agente. Login headless copiando o token OAuth de uma máquina já logada.

OpenRig (rig-dupla) dev

Dupla principal/revisor: Claude Code escreve, Codex revisa o STATE.md. Só conhece esses dois.

6 Secrets

Três níveis em /srv/dev/secrets/. O valor nunca entra no Git — nem em .env versionado, fixture, log ou mensagem de erro. Os .env.example trazem só os nomes das chaves.

Backup dos segredos: as três chaves de backup (R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, RESTIC_PASSWORD) ficam também no gerenciador de senhas. Sem elas não há restore numa VPS nova.

7 PMO & verticais

O painel (:8080, só VPN) mostra todos os projetos das organizações, com estágio, tecnologias e alerta de esquecidos. A coleta roda diária pela API do GitHub.

  • Classificar — empresa, área, cliente, tipo e estágio. Grava na hora em classes.json.
  • Clonar na VPS — traz o repo para /srv/dev/projetos/<pasta>.
  • Verticais — a classificação gera os atalhos /srv/dev/verticais/<empresa>/<área>/<projeto>.
  • Descartar — arquivar (reversível) ou excluir. Repo de cliente só pode ser arquivado.

Organizações cobertas: resper1965, bekaa-trusted-advisors, nessenergy, forense-io, t4isb-infra, familia-almeida.
